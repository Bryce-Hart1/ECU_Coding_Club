# ECU Coding Club

Welcome to the GitHub home of the **ECU Coding Club**! This is a shared resource for students who want to practice programming, learn alongside other Pirates, and revisit the problems we cover at meetings.

Whether you are writing your first program or sharpening skills for interviews and contests, you are welcome here!

## What you'll find

- **Meeting question solutions** — Reference solutions and explanations for the challenges we work through together.
- **C++ resources** — Guides and practice material for learning modern C++ and competitive-programming fundamentals.
- **Python resources** — Beginner-friendly tutorials, exercises, and useful references for Python.

## Meeting solutions

After each meeting, look for that week's problems and solutions in the folder corresponding to the date.

Each meeting folder can include:

- The original problem statements or links
- Solutions in C++ and/or Python
- Notes on the approach, runtime, and common pitfalls

Want to try a problem yourself? Give it an honest attempt before opening the solution!

## Learn C++

These are great places to build your C++ foundation:

- [LearnCpp.com](https://www.learncpp.com/) — A thorough, free C++ tutorial.
- [cppreference](https://en.cppreference.com/w/) — The go-to language and standard-library reference.
- [C++ Core Guidelines](https://isocpp.github.io/CppCoreGuidelines/CppCoreGuidelines) — Practical guidance for writing clearer, safer C++.
- [USACO Guide](https://usaco.guide/) — Structured algorithms and competitive-programming practice.

## Learn Python

Start or grow your Python skills with these resources:

- [Official Python Tutorial](https://docs.python.org/3/tutorial/) — Learn directly from the Python documentation.
- [Automate the Boring Stuff with Python](https://automatetheboringstuff.com/) — Practical projects for beginners.
- [Real Python](https://realpython.com/) — Clear tutorials on Python concepts and projects.
- [Exercism Python Track](https://exercism.org/tracks/python) — Hands-on exercises with community feedback.

## Practice

Keep the momentum going between meetings:

- [Kattis](https://open.kattis.com/) — Well-organized problems for all levels.
- [LeetCode](https://leetcode.com/) — Coding interview-style problems.
- [Codeforces](https://codeforces.com/) — Competitive programming contests and problem sets.


## Join us

Come to a meeting, bring a question, and learn with us. No prior coding experience required.
